# Правила работы с проектом

- Общаться с пользователем по-русски. Объяснять C++ и SQL простыми словами: проект учебный и должен быть понятен на защите.
- После каждого завершённого и проверенного логического этапа создавать отдельный локальный Git-коммит с понятным сообщением.
- Перед коммитом проверять состав изменений и исключения Git. Не включать рабочую базу SQLite и её вспомогательные файлы, сборку или секреты. Схема SQL, генератор демонстрационных данных, исходники, тесты и документация должны отслеживаться.
- Не переписывать историю и не создавать коммиты задним числом. Push выполнять только по явному запросу пользователя.
- Не переходить к следующему этапу и не добавлять новые функции без соответствующего задания пользователя.
