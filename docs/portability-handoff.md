# Дополнение к защите и передаче проекта: Ubuntu

14 сентября 2026, ветка `codex/ml-price-estimation`, исходное состояние `7ee72d7`. Это актуальное дополнение к внешним материалам; оно входит в Git вместе с инструкцией запуска.

Найдены внешние материалы: `02-handoff-next-assistant.md`, `handoff.md`, `01-project-explained.md`, `Svoy-adres-defense-60min.pptx`, `Svoy-adres-defense-60min-ML-stage1.pptx` в Documents пользователя. Они не входят в репозиторий. Старые handoff описывают macOS и более ранний статус ML. Сами внешние файлы/слайды в этом шаге не редактировались; следующие сведения заменяют прежние утверждения о переносимости и нужны при обновлении слайдов:

- Целевая Linux-среда — **Ubuntu 24.04 LTS**. Проверка на ней ещё не выполнена. Не писать на слайде «проверено Ubuntu».
- Реальная среда проверки — macOS 15.0 arm64, Apple Clang 15.0.0, Drogon 1.9.13, SQLite 3.53.4, libsodium 1.0.22; новые ON/OFF сборки и 12/10 CTest прошли. Это не доказательство установки на чистой ОС.
- Для преподавателя использовать [ubuntu.md](ubuntu.md) вместо команд `brew`. Drogon 1.9.13 ставится в пользовательский prefix из тега с Trantor submodule; Ubuntu-пакеты остальных зависимостей ставятся через apt.
- ML уже включает загрузку двух моделей один раз при старте и блок подробностей. Он необязателен, работает на C++; обучение запускается отдельным CLI. Python — только HTTP-тесты. Рекомендации остаются правилами без ML.
- Не переносить бинарники Mac и его build-каталоги. На Ubuntu создать свою базу, обучить свои артефакты. Параметры пути явные; цены, бронирования и история от оценки не меняются.
- На слайде ограничения указать синтетические данные и возможность неположительного линейного прогноза. `lower_clipped` даёт недоступность, не цену 1 AMD. Исходные MAE брать из [ml-price-estimation.md](ml-price-estimation.md), не называть совпадение сериализации качеством.
- Эта ветка не опубликована и не слита с main. До отдельного разрешённого push передавать Git bundle по инструкции; сверять фактический commit, не старый идентификатор из handoff.
- Перед защитой осталось выполнить весь Ubuntu walkthrough и реальные клики на этой ОС, записать версии/вывод тестов. Основной сайт Mac и рабочая база при адаптации не изменялись.
